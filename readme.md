## 为什么选择Deeke？

- **自研 DeekeScript 底层框架**：不靠拼凑脚本堆功能，运行时、兼容性与稳定性长期自控，可持续迭代  
- **多年 RPA 自动化经验沉淀**：从老版本<a href="https://github.com/DeekeScript/ad-dke" target="_blank" rel="noopener noreferrer">“嘀客”</a>一路打磨到 Deeke黑科技，场景理解与风控节奏更成熟  
- **多种行为模式可选**：纯无障碍、Hid 蓝牙、无线 ADB 可切换；识别与输入分离，更接近真人操作  
- **用户体验与 UI 设计领先**：界面简洁、路径清晰，权限引导与任务配置更易上手，降低培训成本  
- **全网首发能力持续领先**：语音评论、评论区采集等能力较早落地，至今仍少有同类型产品具备完整方案  
- **AI 能力可落地**：支持 DeepSeek、豆包、角色评论（AI智能体Agent），智能话术与获客流程打通

## 操作模式：无障碍 / HID / 无线 ADB

| 模式 | 识别方式 | 点击 / 滑动 / 输入 | 适合场景 |
| --- | --- | --- | --- |
| 纯无障碍（默认） | 无障碍 | 无障碍 | 开箱即用、快速验证 |
| Hid 蓝牙 | 无障碍识别界面 | Hid 外设输入 | 更接近人工，推荐日常抖音获客 |
| 无线 ADB | 无障碍识别界面 | 无线 ADB 输入 | 需要更稳定、可控的输入时 |

开启 Hid 或无线 ADB 后，无障碍仅用于识别界面；点击与输入改走对应通道，Hid 强烈推荐。
